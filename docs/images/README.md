# Refreshing the preview

The README image is a real Chromium capture of the starter in its light theme.
It is generated by the same browser checks that verify component styling,
theme changes, accessibility and development reload.

After setup, install the test browser and run the browser checks with the
managed Python interpreter (or use `uv run python`):

```bash
uv run python -m playwright install chromium
uv run python scripts/check_browser.py --artifacts test-results/browser
```

Review the generated desktop and mobile images, then copy
`test-results/browser/light-desktop.png` to `docs/images/starter-preview.png`.
Do not substitute a mockup. Capture a commit that passes the verification
workflow, and keep this image aligned with the demo's actual behavior.
